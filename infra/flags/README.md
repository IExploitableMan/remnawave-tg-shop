# Local flag icons

40 × 30 PNG country/organization icons, downloaded once from the documented
[Flagpedia API](https://flagpedia.net/download/api). `manifest.json` records the
source, dimensions and SHA-256 of each asset. Reports load these local files;
rendering does not request a CDN or publish any diagnostic data.

Flags are decoration alongside the original country codes. Unknown codes and
non-country values (N/A, Yes/No, rate limits) retain their original text.
